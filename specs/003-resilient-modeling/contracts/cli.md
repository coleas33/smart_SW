# Command-Line Additions

## `swreview` (Python)

| Command | Arguments | Effect |
|---------|-----------|--------|
| `swreview check rms` | `--package <dir>`, `--document <id>` (repeatable), `--scope part\|assembly\|equations\|all` (default all), `--json` | Runs the family without the agent; prints findings and coverage in the same shape as the other `check` commands; exit 1 on validation errors, 0 otherwise (violations are output, not exit codes). Reads `exceptions.json` beside the package. |
| `swreview rms types` | `--package <dir>`, `--json` | Lists type names in the package the tables do not classify, with feature counts and documents, for calibration |
| `swreview rms suppress-plan` | `--package <dir>`, `--document <id>`, `--out <file>` (default `<package dir>/suppress-plan.json`), `--json` | Writes the suppress-test plan for one part document: the review configuration, the Detail group name, and the Detail content features in tree order (`feature_id`, `persist_ref`, `persist_ref_scope`, `name`, `type_name`), derived from `features[]` by the group assigner and the type table. The C# command consumes it, so the extractor never decides folders, groups, or content. Exit 1 when the document has no `features[]` rows or no Detail group. |
| `swreview exceptions accept-rms` | `<run_dir>`, `--package <dir>`, `--file <rms_exceptions.json>`, `--by <name>`, `--json` | Imports the checker's flat waiver file `{ "<rule_id>": "<reason>" }`: accepts every `demonstrated` finding of the run whose `check` is a listed `fail` rule (one `ReviewException` each, `fingerprint_kind: feature_tree`, note = reason), writes `exceptions.json`, records `exception_id` on the findings, re-renders the report, and prints per rule id: `accepted <n>`, `would accept <n>` (a matching `fail` rule on a run that exits 1 because another id is invalid, so nothing was written), `unused`, or `invalid (warn rule)` / `invalid (unknown rule)`. Exit 1 when any id is invalid; nothing is written in that case. The `--json` `status` field carries the same four values. |

`swreview exceptions accept` and `exceptions list` work unchanged on RMS findings.

## `swreview-extract` (C#)

| Command | Arguments | Effect |
|---------|-----------|--------|
| `dump` | `--features tree\|none` (default `tree`), `--equations on\|off` (default `on`) | Adds `features[]` and `equations[]` to `package.json` for every resolved part document, once per document; gaps for anything unreadable and for every lightweight, suppressed, or unloaded component. Read-only. |
| `probe rms` | `--doc <part>` | Prints, for one open document: the raw feature walk (index, depth, type name, name, enclosing folder, sub-feature counts) so the traversal shape is visible; whether `GetChildren` and `GetParents` returned values per feature; raw sketch statuses; description readability; equation count and `GlobalVariable` flags; fillet radius readability and the fillet data interface name; the current `GetWhatsWrongCount`; component constrained status, mate entity kinds, and mate feature suppression when the document is an assembly. Read-only; uses the read-only guard. |
| `suppress-test` | `--doc <part>`, `--plan <suppress-plan.json>`, `--acknowledge-rebuild`, `--out <package dir>`, `--limit <n>` (default 50), `--timeout-seconds <n>` (default 900) | Engineer-run mutation under `SuppressTestGuard`, with a recording gate observer whose distinct member names are written to `suppress-test.log`. Refuses, before touching anything: without the flag; when `GetSaveFlag` reports unsaved changes (message: a previous suppress-test run leaves the document modified; close without saving and reopen); when any feature `IsRolledBack`; when the document's active configuration differs from the plan's configuration; when `GetWhatsWrongCount` is already non-zero (message names the pre-existing errors); when the live feature walk differs from the package's `features[]` for this document in count, order, type names, names, depth, or suppression state, or any planned feature fails `IsSamePersistentID` against the live feature (message: dump again). Records the baseline error count, snapshots every feature's suppression state, then for each planned feature in order: skip if already suppressed; `SetSuppression2(suppress, this configuration)`; verify applied (else `not_applied`, no rebuild); `ForceRebuild3(false)`; record `GetWhatsWrongCount` and up to 20 `GetWhatsWrong` messages (`rebuild_errors` when the count exceeds the baseline); restore the whole tree to the snapshot and verify. Stops at the limit or timeout with `truncated` rows. On any exception the restore runs with the breaker reset; unrestored features are named on stderr and in the log; exit code non-zero. Appends `rms_suppress_test` through `PackageAppender`. Never saves. Ends by printing that the document is modified in memory and must be closed without saving. Not available from the add-in, bridge, or MCP. |
